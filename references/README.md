# References

Este repositório não copia especificações externas integralmente.
Ele normaliza regras úteis e mantém links para fontes primárias.

Ao atualizar uma regra:
1. Preferir fonte oficial/primária.
2. Registrar versão quando relevante.
3. Não transformar drafts em requisito obrigatório sem decisão explícita.
4. Evitar reproduzir longos trechos protegidos por copyright.
