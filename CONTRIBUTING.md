# Contributing

Mudanças normativas devem:
1. indicar fonte/referência quando aplicável;
2. usar MUST/SHOULD/MAY de forma deliberada;
3. evitar regras específicas de uma organização no núcleo genérico;
4. manter regras de plataforma isoladas na respectiva stack;
5. incluir exemplos quando reduzirem ambiguidade;
6. considerar automação/linter para regras objetivamente verificáveis.

Mudanças arquiteturais no próprio framework SHOULD usar ADR.
